05 / REFERÊNCIAS

Fundamento e transparência.

Entenda o que o cálculo representa, a procedência das regras e os limites do ambiente.

01

Código-fonte da Receita Federal

A API de Regime Regular é um componente público em Java, executado em infraestrutura própria. Não é uma API hospedada ou um serviço operado pela Receita Federal.

Repositório oficial ↗
02

Simulação e resultado oficial do motor

Os resultados com alíquotas nominais fornecidas para 2027 em diante são classificados pelo motor como CALCULO_SIMULADO. A interface mantém esse aviso; não transforma simulação em apuração.

03

Vigência e base de referência

Consulta de CST, cClassTrib, NCM/NBS e bases de cálculo usa os dados da versão embarcada no serviço Java. Confira o período de vigência antes de aplicar os resultados.

04

Privacidade e responsabilidade

O navegador não mantém histórico persistente das operações. Quando você solicita o cálculo, os dados seguem para os serviços configurados na Vercel e no Render. Não há transmissão ou autorização de documentos fiscais.
